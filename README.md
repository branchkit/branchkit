# BranchKit

An accessibility plugin platform for the desktop, on macOS, Windows and Linux.
Every way in, from voice commands and dictation to keyboard, browser and other
input, comes from a plugin, and anyone can write one.

**Pre-launch.** The app is in private development and its source is not
public. This repository is where its problems and ideas are tracked in the
open. The SDKs, tooling and public plugins are listed on the
[BranchKit organization page](https://github.com/branchkit).

## Report a problem

The easiest way is from BranchKit: **Help → Report a problem…** (also in the
menu bar or tray menu). Describe what happened and click **Write up the
issue**: BranchKit adds its version, your operating system and a short summary
of the warnings and errors it recorded. You read and change all of it, then
**Open on GitHub** opens the issue here, filled in, for you to submit.

Or open a [bug report](../../issues/new?template=bug-report.yml) yourself.

Everything here is public. If we need BranchKit's full logs, we'll ask you for
its report file privately: please don't attach it to an issue.

- **A problem in one plugin?** If the plugin has its own repository, report
  it there; BranchKit's report page sends you to the right place.
- **Building a plugin** and hit a bug in an SDK or the CLI? Report it in that
  repository, such as [plugin-sdk-go](https://github.com/branchkit/plugin-sdk-go/issues).
- **A security problem**, such as a way for a plugin to get outside what it
  was allowed? Please report it privately:
  [Report a vulnerability](../../security/advisories/new). Don't open a
  public issue.
